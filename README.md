# Portfolio Website

This project of mine is a personal portfolio website created using HTML5 and CSS3 files.

The website contains four pages/sections:
- Home
- About Me
- Projects
- Contact Me

## Responsive Design

The website uses three separate CSS files for different screen sizes:

- `full.css` is used for screens that are 960px and wider, such as laptops.
- `tablet.css` is used for screens from 481px to 959px.
- `smartphone.css` is used for screens that are 480px and smaller.

These screen sizes were based on the responsive design examples used in the course lectures. The tablet and smartphone layouts use a fluid width of 100% so the website can adjust to smaller screens.

## Color Scheme

The website I made has a cream and blue color scheme. I used the blue and cream colours from the Lecture 3 in-class `full.css` example color palette.


The main colors are:

- `#F2E2CE`
- `#23B7D9`

 I chose these colors because they are very simple, while they also keep the text easy to read for viewers.

## Gradient

A linear gradient is used for the background of the website. The gradient changes from cream to blue from the top to the bottom of the page.

The gradient is included in the CSS files using the `linear-gradient` property.
